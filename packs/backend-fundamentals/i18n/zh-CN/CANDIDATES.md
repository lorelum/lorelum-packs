# 决策选择与边界

> 对应 [英文原文](../../CANDIDATES.md)。仅供人工审阅，不参与运行时加载、检索或评估；英文为准。

本 Pack 包含 30 条面向 Agent 的英文 Practice。每条保留一个决策、一段简短流程及其停止条件、一个具体故障，以及单独检索时必需的约束。详细技术证据放在来源映射中，而不是重复编写教程。

## 决策边界

- 入口访问建立不可绕过的调用方边界；资源授权决定对特定目标可执行的动作，包括公开可见性。可写字段绑定限制已授权操作内的赋值范围：拥有记录权限、数据类型有效，不代表可写模型的所有字段。
- CSRF 防护保护使用浏览器环境自动携带凭据的写入。浏览器来源的响应访问控制决定哪些脚本可以读取响应，而不是授予变更权限。Webhook 验证认证提供方的签名消息；通过入口身份验证不代表允许任意出站目的地，后者需要覆盖 DNS 和重定向的控制。
- HTTP 失败处理定义对外状态和表示；日志选择安全的诊断内容。两者各自保留必要的最小秘密排除规则。个性化缓存隔离管理源站授权执行之前的存储与复用，因此仅有目标权限检查无法保护共享缓存命中。
- 分页限制读取规模并定义后续遍历；关联批量读取控制重复查询，同时保留子记录筛选条件。索引评估针对具体访问路径，也可以得出不加索引的结论。
- 数据库唯一性执行键约束；关联行完整性执行父子身份和删除规则，唯一性与调用方权限都不保证这些规则。当前状态写入保护协调竞争更新和状态迁移条件；仅有事务并不能防止丢失更新。
- 本地事务将必需写入绑定在一起；事件去重将持久化事件认领与其本地效果绑定。两者均不承诺远程效果恰好一次。精确金额还需要表示方式、币种、计价单位和舍入决策；原子写入无法修复已经失真的金额。
- 已获取客户端连接的清理与部署连接池预算有独立触发条件。启动和恢复时的就绪状态决定能否接收所声明的流量；关停负责安排停止接收、在途工作和依赖释放，而不是获取连接。
- 上传存储键让目的地选择由服务端掌控，不会自动保证授权或内容安全。内容接纳决定哪些真实字节可被处理和提供。结构退役根据实际已部署调用方和在线数据迁移情况，为破坏性变更设置门槛。

## 不包含的范围

通用校验责任归属，以及调用方重试／回退策略，仍归 `agentic-coding` 负责。接收方持久化事件去重是独立的后端决策。不引入强制框架、身份验证平台、分布式事务、队列、outbox、通用索引公式或统一限流阈值。
